Upgraded Omni-directional Isometric Render(er)

Upgraded fork of: https://s3rdia.itch.io/omnidirectional-isometric-render

Added features:
-Select multiple specific actions to render at a time (no longer all or 1)
-Export each direction as its own sprite sheet
-Animation frames can automatically set to the length of the action being rendered (useful for large list of diverse actions)
-Progress bar! Watch 10,000 frames render in real time! Better than paint drying!

To install:
Edit -> Preferences -> Add-ons -> Install from disk -> Enjoy
(Make sure it is enabled)
