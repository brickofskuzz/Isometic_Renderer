### Upgraded Omni-directional Isometric Render(er)
<br>
Upgraded fork of: https://s3rdia.itch.io/omnidirectional-isometric-render
<br>
Added features:
<br>-Select multiple specific actions to render at a time (no longer all or 1)
<br>-Export each direction as its own sprite sheet
<br>-Animation frames can automatically set to the length of the action being rendered (useful for large list of diverse actions)
<br>-Progress bar! Watch 10,000 frames render in real time! Better than paint drying!
<br>
To install:
<br>Edit -> Preferences -> Add-ons -> Install from disk -> Enjoy
<br>(Make sure it is enabled)
